# Fabio Zapata

My personal website: a little about me, my work, personal projects, and contact information.

Plain HTML and CSS. No dependencies or build step.

## Edit

Update `index.html` to change the content or styles. The portrait is `fabio-zapata.jpeg`.
Open `index.html` in a browser to preview the site.

## Deploy to Vercel

Import this repository and choose **Other** as the framework preset.
Override the build command and leave it empty. Use the repository root (`.`) as the output directory.

Documentation: https://vercel.com/docs/builds/configure-a-build

## Deploy to Cloudflare Pages

Connect this repository to a Pages project. Choose no framework preset, use `exit 0` as the build command, and `.` as the build output directory.

Documentation: https://developers.cloudflare.com/pages/framework-guides/deploy-anything/
